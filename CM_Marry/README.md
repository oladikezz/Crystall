# SM_Marry - Система браков

**Версия:** 1.0.6

## 📋 Описание
Модуль для SMPS, добавляющий систему браков на сервер Minecraft.

## ✨ Возможности
- 🤵 Священники могут заключать браки между игроками
- 💍 Оба игрока должны подтвердить брак командой `/marry confirm`
- 💔 Священники могут разводить игроков
- ⏱️ Настраиваемое время на подтверждение (по умолчанию 30 секунд)
- 📊 Просмотр информации о браках
- 📋 Список всех браков на сервере
- 🗄️ Сохранение браков в базу данных
- ❤️‍🩹 Общий урон для пары - когда один из партнёров получает урон, второй тоже получает урон (настраивается)
- 🐱 Звуки кота при браке, разводе и когда один партнёр бьёт другого

## 🎮 Команды

### Для священников (требуется право `smmarry.priest`):
- `/marry <ник1> <ник2>` - Создать запрос на заключение брака
- `/marry divorce <ник1> <ник2>` - Создать запрос на развод

### Для администраторов (требуется право `smmarry.admin`):
- `/marry admin marry <ник1> <ник2>` - Принудительно заключить брак без подтверждения
- `/marry admin divorce <ник1> <ник2>` - Принудительно развести без подтверждения

### Для игроков:
- `/marry confirm` - Подтвердить брак или развод
- `/marry deny` - Отклонить брак или развод
- `/marry info [ник]` - Посмотреть информацию о браке игрока
- `/marry list` - Посмотреть список всех браков на сервере

### Алиасы:
- `/marriage`
- `/wed`

## 🔑 Права доступа
- `smmarry.priest` - Право для священника (заключение браков и разводов)
- `smmarry.admin` - Право для администратора (принудительные браки и разводы без подтверждения)
- `smmarry.use` - Базовое право на использование команд (автоматически для всех)

## ⚙️ Настройки (config.yml)

```yaml
commands:
  marry:
    enabled: true

settings:
  # Время на подтверждение брака/развода (в секундах)
  confirmation-timeout: 30
  
  # Требовать ли обоих игроков онлайн
  require-both-online: true
  
  # Разрешить ли жениться на себе (для теста)
  allow-self-marry: false
  
  # Максимальное количество браков на игрока
  max-marriages-per-player: 1
  
  # Публичные объявления о браках и разводах на весь сервер
  broadcast-marriages: true
  broadcast-divorces: false
  
  # Звуки котов при браках и разводах
  sounds:
    enabled: true  # Включить звуки
    marriage-sound: ENTITY_CAT_PURR  # Звук брака (мурлыканье)
    divorce-sound: ENTITY_CAT_HISS   # Звук развода (шипение)
    volume: 1.0    # Громкость (0.0 - 1.0)
    pitch: 1.0     # Высота (0.5 - 2.0)
  
  # Общий урон для пары
  shared-damage:
    enabled: true          # Включить общий урон
    damage-percent: 0.5    # Процент урона для партнёра (0.5 = 50%)
  
  # Звук когда один партнёр бьёт другого
  partner-pvp-sound:
    enabled: true          # Включить звук при PvP между парой
    sound: ENTITY_CAT_HURT # Звук (мяуканье боли)
    volume: 1.0            # Громкость
    pitch: 1.0             # Высота
```

## 📝 Как это работает

1. **Заключение брака:**
   - Священник пишет `/marry Player1 Player2`
   - Player1 и Player2 получают уведомление
   - Оба игрока должны написать `/marry confirm` в течение 30 секунд
   - Если оба подтвердили - брак заключен! ❤️
   - Священник получает уведомление о результате
   - Если включено `broadcast-marriages`, на сервер идет публичное объявление
   - Если кто-то написал `/marry deny` - брак отменен, священник узнает кто отказался
   - Если время истекло - священник получает уведомление о таймауте

2. **Развод:**
   - Священник пишет `/marry divorce Player1 Player2`
   - Player1 и Player2 получают уведомление
   - Оба игрока должны написать `/marry confirm`
   - Если оба подтвердили - развод оформлен 💔
   - Священник получает уведомление о результате
   - Если включено `broadcast-divorces`, на сервер идет публичное объявление
   - Если кто-то написал `/marry deny` - развод отменен, священник узнает кто отказался

3. **Административные команды:**
   - Администратор может использовать `/marry admin marry Player1 Player2` для мгновенного заключения брака
   - Администратор может использовать `/marry admin divorce Player1 Player2` для мгновенного развода
   - Не требуется подтверждение от игроков
   - Игроки получают уведомление о действии администратора
   - Если включены публичные объявления, они будут отправлены на сервер

4. **Общий урон для пары:**
   - Когда один из партнёров получает урон, второй партнёр тоже получает урон
   - По умолчанию партнёр получает 50% урона от оригинального
   - Работает для любого типа урона (PvP, PvE, падение, огонь и т.д.)
   - Звуки при этом НЕ воспроизводятся

5. **Звук при PvP между партнёрами:**
   - Когда один партнёр бьёт другого, оба слышат мяуканье боли (`ENTITY_CAT_HURT`)
   - Работает только при прямых атаках между партнёрами
   - Можно отключить в конфиге: `partner-pvp-sound.enabled: false`
   - Можно настроить процент урона или полностью отключить в конфиге
   - Партнёр должен быть онлайн, чтобы получить урон

## 🔔 Уведомления

**Священник получает уведомления:**
- ✓ Успешное заключение брака/развода
- ✗ Отказ от брака/развода (с именем отказавшегося)
- ✗ Таймаут подтверждения

**Публичные объявления на сервер:**
- Браки (если `broadcast-marriages: true`)
- Разводы (если `broadcast-divorces: true`)

## � Звуковые эффекты

- 🐱 **Мурлыканье кота** (`ENTITY_CAT_PURR`) - при заключении брака
- 😾 **Шипение кота** (`ENTITY_CAT_HISS`) - при разводе
- 😿 **Мяуканье боли** (`ENTITY_CAT_HURT`) - когда один партнёр бьёт другого
- Звуки брака/развода слышат: священник и оба игрока в паре
- Звук PvP слышат: оба партнёра когда один бьёт другого
- Настраивается в `config.yml` (можно отключить или изменить звуки)

## �🗄️ База данных

Модуль создает таблицу `sm_marry_marriages` со следующей структурой:
- `id` - ID брака
- `player1_uuid` - UUID первого игрока
- `player1_name` - Имя первого игрока
- `player2_uuid` - UUID второго игрока
- `player2_name` - Имя второго игрока
- `married_date` - Дата заключения брака

## 📦 Установка

1. Скомпилируйте модуль: `./gradlew :SM_Marry:build`
2. Найдите JAR в `SM_Marry/build/libs/SM_Marry-1.0.6.jar`
3. Поместите в папку `plugins/SMPS/modules/`
4. Перезагрузите модули: `/sm reload` или перезапустите сервер

## 🐛 Поддержка

При возникновении проблем проверьте:
- Подключена ли база данных к SMPS
- Есть ли у священника право `smmarry.priest`
- Есть ли у администратора право `smmarry.admin` для админ-команд
- Онлайн ли оба игрока при заключении брака
- Логи в `plugins/SMPS/logs/`
